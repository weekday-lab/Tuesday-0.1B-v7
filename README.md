# 数据来源
本模型的预训练语料来自 FineWeb-Edu-Chinese V2.1、SkyPile-150B、MAP-CC、中文维基百科、THUCNews、百度百科问答等网络公开可获取的数据集；SFT 数据基于 BELLE train_0.5M_CN 与 train_3.5M_CN 构建；DPO 偏好数据由本项目模型自生成并经内部裁判标注。上述部分数据集（BELLE、MAP-CC、THUCNews）的使用条款限制为研究用途，因此本模型权重仅限研究与非商业用途；如需商用，请联系我们获取经数据清洗的商用版本。
